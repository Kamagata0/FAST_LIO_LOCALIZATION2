# 【仕様書】ロボコン2026特化型 超高速LiDAR自己位置推定＆機構データ統合サーバーシステム

- **文書番号**: SPEC-ROBOCON-2026-001
- **作成日**: 2026年9月11日
- **対象環境**: NVIDIA Jetson (Orin / Xavier) / ROS 2 Humble

---

## 1. システム概要と開発方針

### 1.1 背景と目的
従来の汎用LiDAR SLAM（FAST-LIO等）は未知環境での頑健性に優れる一方、以下の課題を抱えています：
1. **初期位置の手動指定** または **外部オドメトリ（車輪/IMU）** が必須。
2. 競技中のスリップや急激な加減速によるオドメトリドリフトの蓄積。
3. 汎用KD-Treeや反復ICPによる計算負荷（数十ms）。

本システムは、**「競技フィールドの幾何構造（外壁寸法・中央教壇）が完全既知である」** というロボコン特有の前提を最大限に活用し、**「オドメトリ不要・初期位置不要・ブラックボックスゼロ・超高速（<5ms）」** な特化型自己位置推定システムを新規構築します。
併せて、Jetsonをロボット全体のROS 2データサーバーとして位置づけ、ベルト直動・シリンダ状態・ターゲット相対情報を一元管理・可視化・ワンコマンド記録します。

## 3. 機能要件・詳細仕様

### 3.1 点群処理 ＆ 超特化自己位置推定 (`field_localization_node`)

#### 処理パイプライン（5段階）
1. **空間フィルタリング (Passthrough / ROI)**
   - LiDAR原点から半径 $R \le 12.0\,\text{m}$ の点群を抽出。
2. **床面除去 (Ground Filter)**
   - $Z$ 座標閾値（$Z < 0.05\,\text{m}$）および 2D 平面 RANSAC により床面点群を完全カット。
3. **外壁4辺の幾何フィッティング (Arena Boundary Fit)**
   - 点群を水平2Dに投影。
   - RANSAC 直線検出または主軸解析（PCA）により、フィールド長方形の主軸角度 $\theta$ と中心 $(X_c, Y_c)$ を直接幾何計算。
4. **自陣/敵陣（180度反転）の曖昧性解消**
   - 中央の教壇および特定オブジェクトの重心位置を比較し、自陣・敵陣の180度反転を一意に決定。
   - **出力周期**: 50〜100Hz（処理時間 < 5ms）。
   - **オドメトリ・初期位置入力**: **完全不要**。
5. **ターゲットオブジェクト抽出**
   - 外壁・教壇以外の残存クラスタから、ターゲット（ボール／台座）の重心位置を算出。
   - ロボット中心、ベルト直動リンク、エアシリンダ基準での相対距離 $D_{\text{target}}$ と方位角 $\phi_{\text{target}}$ を算出。

---

### 3.2 ロボット機構データサーバー ＆ 2D HUD可視化 (`robot_dashboard_node`)

#### 管理・統合するデータ項目
- **ベルト直動**:
  - 目標速度 $V_{\text{target}}$ [m/s]
  - 実効（現在）速度 $V_{\text{actual}}$ [m/s]
  - 偏差 $\Delta V = |V_{\text{target}} - V_{\text{actual}}|$
- **エアシリンダ**:
  - 展開／格納状態（ON/OFF）
  - ターゲット方向に対するアライメント偏差角 $\Delta \theta_{\text{align}}$
- **ターゲット情報**:
  - ロボットから見たターゲットの距離 $D$ [m]、向き $\theta$ [deg]

#### 2D HUD 描画仕様
OpenCVを用いて $800 \times 600$ の 2D 俯瞰画像をリアルタイム生成（トピック: `/robot_dashboard/image`）：
- **フィールド枠・教壇**: 白・グレー線
- **ロボット車体**: 矩形アイコン + 進行方向ベクトル
- **シリンダ・ベルト直動**: 機構の向きを示すカラーライン
- **ターゲット**: 赤/黄色のマーカー + ロボットから結ぶ追従線（距離・角度テキスト付き）
- **HUDテレメトリ表示（画面右上）**:
  - `Belt Target:  X.XX m/s`
  - `Belt Actual:  X.XX m/s`
  - `Target Dist:  X.XX m`
  - `Target Angle: XX.X deg`
  - `Cylinder:     DEPLOYED / RETRACTED`

### 3.3 ワンコマンド rosbag 記録システム (`record_all.sh`)

- **実行コマンド**: `bash scripts/record_all.sh [オプション: タグ名]`
- **記録対象トピック**:
  - `/livox/lidar` (または `/livox/lidar_custom`)
  - `/robot_pose` (絶対位置姿勢)
  - `/target_relative` (ターゲット相対距離・方位)
  - `/robot_status` (ベルト速度・シリンダ状態)
  - `/robot_dashboard/image` (2D HUD描画画像)
  - `/tf`, `/tf_static`
- **保存形式**: `rosbag2` (MCAP / SQLite3)、日時別ディレクトリ自動生成（例: `bag_YYYYMMDD_HHMMSS/`）。

## 4. ROS 2 トピック・メッセージ定義

### 4.1 カスタムメッセージ定義案: `RobotStatus.msg`
```text
std_msgs/Header header

# ベルト直動
float64 belt_target_speed    # 目標速度 [m/s]
float64 belt_actual_speed    # 実効速度 [m/s]

# エアシリンダ
bool cylinder_deployed       # シリンダ展開フラグ (True: 展開, False: 格納)

# ターゲット相対情報
bool target_detected         # ターゲット検出成否
float64 target_distance      # ターゲットまでの距離 [m]
float64 target_angle_rad     # ターゲットの方位角 [rad]
float64 target_angle_deg     # ターゲットの方位角 [deg]
```

### 4.2 主要配信トピック一覧
| トピック名 | 型 | 配信元 | 周期 | 説明 |
|---|---|---|---|---|
| `/robot_pose` | `geometry_msgs/msg/PoseStamped` | `field_localization_node` | 50Hz | グローバル絶対位置姿勢 |
| `/target_relative` | `geometry_msgs/msg/PointStamped` | `field_localization_node` | 50Hz | ターゲット相対位置 |
| `/robot_status` | `fast_lio_localization/msg/RobotStatus` | `robot_dashboard_node` | 50Hz | 機構統合ステータス |
| `/robot_dashboard/image` | `sensor_msgs/msg/Image` | `robot_dashboard_node` | 30Hz | 2D HUD描画画像 |
